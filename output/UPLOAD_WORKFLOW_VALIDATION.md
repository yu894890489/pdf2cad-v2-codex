# 本地上传与可复用流程验证

日期：2026-10-25。

## 实现范围

- `tower_rebuild/workflow.py`：统一完整流程入口 `process_drawing`；检查输入、复制来源 PDF、读取 BOM 与原生图元、整理逐面拓扑及重叠段、尺寸初审、完整性检查、三维预览。调用现有通用模块，不包含针对某张图的手工坐标或件号分支。
- `tower_rebuild/studio.py` 和 `studio_web/`：本地上传、多文件顺序处理、真实阶段与耗时、历史记录、查看结果、失败重试。每个任务使用独立进程和输出目录。
- `start-local.ps1`：启动本地上传工作台，默认 `http://127.0.0.1:8770/`。
- `run-pipeline.ps1` / `python -m tower_rebuild process`：新图纸的一条命令入口；与上传页面共用同一流程。
- 原有分阶段命令、人工复核文件与可配置 Qwen/vLLM 流程继续保留。上传工作台不自动调用远程模型。

## 失败与隔离检查

- **123 项 Python 测试通过**，其中新增 7 项覆盖上传/流程边界。
- 没有原生线条或文字的 PDF 返回 `unsupported`，保留源文件和原因，不显示生成成功。
- 输入路径错误返回 `failed`，写明失败阶段。
- 完整流程拒绝覆盖已有结果目录；旧数据保持原状。
- 同名文件生成不同任务 ID，重试也创建新目录。
- 启动时将上次未完成记录标为中断，可重试。
- 上传要求当前本机页面的会话 token；非 PDF 内容被拒绝，结果路由不可越过该任务的网页目录。
- Windows PowerShell 5.1 解析两个新脚本通过；二者均为 ASCII。已实际运行 `run-pipeline.ps1 -NoServe` 的不支持输入路径，正确输出 `unsupported` 并正常退出，没有字符串编码错误。

## 使用边界

当前完整本地流程针对有可读原生文字和矢量线条的工程 PDF。扫描图、未读出 BOM、旋转元数据等情况明确提示需要进一步处理。不同设计院格式和复杂遮挡可能留下更多缺项；“程序可复用”不等于“任意图纸无需复核即可准确生成”。

三维结果仍为每个结构面的基础候选实体。空间装配、部分板形、杆件完整端点、角钢朝向与孔径等未确认内容继续保留在报告中。零件观察数不作为实物数量验收。
