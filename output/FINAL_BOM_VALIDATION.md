# 最终模型 BOM 验证

日期：2026-11-07。

## 功能

- 自动装配结果发布时生成 `site/final-bom/`；已有结果可用 `python -m tower_rebuild final-bom --out <run>` 导出。
- 装配项目的“当前模型 BOM”在每次读取时重新量取已保存的有效几何，包含反算、单线图修正和当前面比例。读取不执行装配求解，不改变摆放或连接。
- 原图表格的件号、规格、长度、数量保留。单重、总重、备注须在件号、规格、长度、数量及表 ID 一致且唯一时对应；完整原始单元格保留在 JSON 和页面中。
- 杆件量取最终 `a`、`b` 三维端点；不读取旧的 `projected_preview_length_mm`。多视图长度不平均，观察数不当作实物数量，不同 PDF 的件号命名空间不合并。
- 连接板包络长边与下料长区分；无板形时不填造长度，也不计为已修正板形。
- 最后一列为“是否需要人工关注”，前一列列出原因。包含漏建、缺毫米比例、端点未确认、反算候选、长度差、跨面长度冲突、接缝未通过、单线图待核对及实物数量未唯一对应等。
- 输出 HTML、UTF-8 BOM CSV、逐组件 CSV、JSON。HTML 对原表文字转义；CSV 对公式前缀保护。最终表不缓存，文件使用原子替换；下载路径白名单验证。
