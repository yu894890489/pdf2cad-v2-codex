# 按最终模型拆分零件放样 DWG

日期：2026-11-07。生成器格式版本：2。

## 生成规则

- 使用当前装配快照及最终 BOM，不重跑装配、不移动模型。
- 图纸、件号、规格、实际长度、轮廓和孔位共同定义零件变体；完全相同的模型观察合并，不把观察数当作实物数量。同件号长度冲突分别出图，不取平均。
- 角钢两肢侧视图和 L 形截面按模型长度及截面出图。未建模的端切、火曲、圆角和孔所属肢面在图内注明，不补造加工细节。
- 板件保存多边形、长宽、板厚、顶点坐标和有依据的孔中心/直径。无有效轮廓、毫米比例或支持截面的记录保留未生成原因。
- 原图 BOM 长度、原图数量、备注和结构面来源随图保存，数量尚未分配到长度变体。

## CAD 与下载实现

使用本机 AutoCAD 2025 Core Console，从 DXF 生成 DWG 2018。隐藏进程、隔离配置、参数列表调用，无 shell 拼接模型文字。中文标注使用实际安装的 `simhei.ttf`；SVG 将字体转为轮廓，使用固定预览纸张和页边距。

每份 DWG 验证 `AC1032` 文件头，再由 AutoCAD 重新打开并转回 DXF，检查毫米单位、闭合轮廓、L 形截面、孔圆、所有多行文字及尺寸标注测量值。没有转换器、转换失败、超时或回读不一致时不标记成功，不将错误文件纳入成功 DWG 包。

后台转换单工作线程，队列有界，长操作不占用全局模型锁。POST 要求会话令牌、请求大小和整数修订号；下载仅允许已知项目、版本 ID 和清单文件名。旧输出保留，模型几何变化时标记过期。

入口：装配页“零件放样 DWG”、最终 BOM 页“按模型生成零件放样 DWG”。页面支持进度、逐件 DWG/DXF 下载、SVG 预览和全部 DWG ZIP。CLI 为 `python -m tower_rebuild part-drawings --out <run>`。
